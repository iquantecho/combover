# Changelog

## 0.3.0 - 2026-11-13

- Centered Combover on the lazy senior knowledge worker: good work, on time, with practical 80/20 judgment.
- Added an explicit finish line based on intended use, required coverage, material checks, and the value of further work.
- Adapted Ponytail 5's lessons on complete scope, affected dependencies, meaningful verification, and concrete review findings.
- Sharpened guidance for pitch decks, spreadsheets, financial models, research, writing, and operational work.
- Refreshed package descriptions while preserving one canonical skill, four optional references, and the existing modes.

## 0.2.0 - 2026-09-29

- Initial public cross-harness package.
- One canonical Combover skill with Research, Finance, Review, and Cleanup references.
- Portable Agent Plugin manifest plus Claude Code, Codex, GitHub Copilot, Cursor, Gemini, Windsurf, and Qoder compatibility files.
- Added macOS/Linux and PowerShell fallback installers.
- Added zero-dependency validation and GitHub Actions CI.
- Added explicit credit to Ponytail by Dietrich Gebert as the original inspiration.
