# Combover Review

Use this reference for a requested simplification review of an existing artifact, plan, workflow, task, document, or operating process.

Default to read-only unless the user asked you to edit.

## Method

1. Read the whole affected artifact and enough surrounding context to understand what each part is doing.
2. Preserve explicit requirements, safeguards, evidence, settled decisions, and unique history.
3. Find concrete cuts: duplicate steps, repeated metadata, obsolete sections, parallel sources of truth, speculative machinery, needless handoffs, and explanations that do not help the next action.
4. Prefer one authoritative replacement over several overlapping artifacts.
5. Identify exact locations and the smallest replacement when useful. Do not answer with generic advice like "simplify this."
6. Surface material correctness problems separately. A simplification review does not certify that everything else is correct.
7. Do not turn the review into a redesign unless the current structure genuinely blocks the requested outcome.

## Output

Return the simplified artifact when edits were requested. Otherwise return a short cut list ordered by impact, with exact replacements or deletions. Avoid scores, ceremonies, and speculative future architecture.
