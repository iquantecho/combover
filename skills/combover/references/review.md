# Combover Review

Use this reference for a requested quality or simplification review of a deck, model, report, plan, workflow, task, or operating process.

Default to read-only unless the user asked you to edit.

## Method

1. Establish the intended audience, use, and requested review scope. Read the affected artifact and enough connected evidence to understand it.
2. Trace the decision chain where relevant: source, calculation, chart, claim, recommendation. Check related outputs as well as the changed paragraph or cell.
3. Prioritize misleading claims, wrong calculations, missing requirements, and consequential risks. Then address usability and unnecessary work. Keep a simplification review focused; flag material correctness issues without implying a full audit.
4. Preserve safeguards, unique evidence, house conventions, and settled decisions. Accept a deliberate approximation while its stated limit fits the intended use. Reopen it only when that limit is crossed or evidence shows a concrete problem.
5. Find useful cuts: duplicates, obsolete material, parallel sources of truth, speculative machinery, needless handoffs, and explanations that do not help the next action.
6. Confirm each finding. Name its location, the concrete failure or waste, the consequence, and the smallest sufficient fix. Reject vague worries and personal style preferences unless design critique was requested.
7. Edit only within the authorized scope. Fix shared sources and affected outputs together. Keep the current structure unless it blocks the outcome.

## Output

Return the revised artifact when edits were requested. Otherwise, give a short numbered list ordered by impact. Distinguish fixes needed for the intended use from optional polish; skip empty groups. State whether it is ready for that use and any material limit to the review.

If no material issue remains, say it is ready and stop. Do not invent findings to fill a template or turn an acceptable artifact into a redesign project.
